CAP CENTIX

Sistema integral de Control de Asistencia Personal. Registra, procesa y reporta los eventos de los 90 colaboradores de Centix en tiempo real.

Firebase Firestore Vercel Hosting ZKTeco Biométrico $0 / mes
Objetivo
🎯
Problema

Controlar la asistencia de ~90 colaboradores con múltiples eventos diarios (entradas, permisos, tardanzas, salidas) sin hojas de cálculo manuales.

⚡
Solución

App web en tiempo real con login por DNI, registro de 27 tipos de eventos, dashboard por supervisor y exportación directa a Excel.

♾️
Resultado

Infraestructura 100% gratuita con más de 20 años de capacidad disponible. Accesible desde cualquier dispositivo con navegador.

Herramientas utilizadas
🔥
Firebase Firestore

Base de datos NoSQL en la nube. Almacena usuarios y marcaciones. Se actualiza en tiempo real sin refrescar la página.

Gratis · Spark Plan
▲
Vercel

Hosting del sitio web. Deploy automático al hacer cambios en GitHub. HTTPS incluido y acceso global desde cualquier red.

Gratis
📊
SheetJS (xlsx)

Librería JavaScript para leer el Excel del biométrico ZKTime y generar los reportes descargables en formato .xlsx.

CDN · Sin instalación
🖐️
ZKTeco / ZKTime

Lector biométrico de huella dactilar. ZKTime es el software que exporta el registro de accesos en Excel al final del día.

Hardware externo
🌐
HTML · CSS · JavaScript

La app completa es una sola página HTML. No requiere frameworks ni instalaciones. Funciona en cualquier navegador moderno.

Sin dependencias
🐙
GitHub

Control de versiones del código. El repositorio está conectado a Vercel para hacer deploy automático al guardar cambios.
