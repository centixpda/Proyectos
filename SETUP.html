⚙️ Guía de Configuración · Centix Asistencia (GAP)

Sigue estos 6 pasos para dejar el sistema de asistencia funcionando en línea, totalmente gratis.

1

Crear proyecto en Firebase

  1. Ve a console.firebase.google.com
  2. Clic en "Agregar proyecto" → Nombre: centix-asistencia
  3. Desactiva Google Analytics si no lo necesitas → Crear proyecto
  4. Espera que se cree y haz clic en Continuar
2

Registrar la app web y copiar credenciales

  1. En el panel del proyecto haz clic en el ícono </> (Web)
  2. Nombre: centix-web → Registrar app
  3. Copia los valores del bloque firebaseConfig
  4. Abre index.html con VS Code o el Bloc de notas
  5. Busca la sección marcada const FB_CFG = {
  6. Reemplaza cada valor de ejemplo con los reales
const FB_CFG = { apiKey: "AIzaSy...", // ← pega tu valor authDomain: "centix-asistencia.firebaseapp.com", projectId: "centix-asistencia", storageBucket: "centix-asistencia.appspot.com", messagingSenderId: "1234567890", appId: "1:1234...:web:abc..." };
⚠️ No subas el apiKey a un repositorio público. Las reglas de Firestore controlan el acceso real.
3

Activar Firestore y configurar reglas

  1. Menú izquierdo → Build → Firestore Database → Crear base de datos
  2. Modo de producción → Región: us-central1 → Listo
  3. Ve a la pestaña Reglas y pega:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /usuarios/{dni} { allow read, write: if true; } match /marcaciones/{doc} { allow read, write: if true; } } }
  1. Clic en Publicar
ℹ️ Las reglas abiertas son suficientes para empezar. El acceso real está controlado por la lógica de login (DNI + contraseña) dentro de la app.
4

Crear índices compuestos en Firestore

Las consultas de reportes necesitan índices compuestos. Ve a Firestore → Índices → Compuestos → Agregar índice y crea estos dos:

Índice 1 — para reportes de supervisor:

Colección : marcaciones Campo 1 : supervisor_dni (Ascendente) Campo 2 : fecha (Ascendente) Campo 3 : __name__ (Ascendente)

Índice 2 — para historial personal del asesor:

Colección : marcaciones Campo 1 : dni (Ascendente) Campo 2 : fecha (Ascendente) Campo 3 : timestamp (Descendente)
ℹ️ Alternativa rápida: cuando la app arroje el error "The query requires an index", haz clic en el enlace que aparece en la consola del navegador (F12) — te lleva directo a crearlo con un clic.
5

Cargar los usuarios iniciales en Firestore

Ve a Firestore → Datos → Agregar colección: usuarios. Agrega un documento por cada persona:

// Documento ID = DNI del usuario (ej: "12345678") { "dni": "12345678", "nombre": "Juan Carlos Pérez López", "rol": "asesor", // asesor | supervisor | admin "supervisor_dni": "87654321", // DNI del supervisor (vacío para supervisores/admin) "password": "12345678", // contraseña por defecto = su propio DNI "activo": true }

Flujo sugerido:

  1. Crea primero los administradores (rol: admin, supervisor_dni: "")
  2. Crea los supervisores (rol: supervisor, supervisor_dni: "")
  3. Crea los asesores asignando el DNI de su supervisor en supervisor_dni
✅ Desde la app, un admin puede crear y editar usuarios desde la pestaña Usuarios. Solo necesitas crear el primer admin manualmente.
6

Publicar en GitHub Pages (gratis)

  1. Crea cuenta en github.com si no tienes
  2. New repository → Nombre: centix-asistencia · Público · Create
  3. Sube index.html y LOGO.png al repositorio
  4. Ve a Settings → Pages → Branch: main / root → Save
  5. En ~2 minutos tendrás la URL:
    https://tuusuario.github.io/centix-asistencia/
⚠️ GitHub Pages es sensible a mayúsculas. El archivo es LOGO.png (mayúsculas) — súbelo exactamente así.
